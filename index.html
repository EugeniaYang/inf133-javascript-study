Start with index.html
Keep the files together in the same folder and open index.html in a browser. Everything needed for the study page is included. No installation, server, or internet connection is required for the local exercises.
The original slide link and documentation links require an internet connection.
How the files connect
index.html provides the page structure. style.css styles it. Standard script tags connect study-data.js and app.js to the page.
Each example is the code from one original slide. The examples and exercises folders contain separate .js files. The main examples.js, practice.js, and solutions.js files contain the first example and average exercise. You can load your own edited practice.js through the Practice section.
